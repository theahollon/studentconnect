# Utils

Utility functions and helper modules for the Student Connect application.

## Purpose
This folder contains reusable utility functions, constants, and helper modules that are used across the application.

## What goes here:
- **Data formatting functions** (dates, strings, numbers)
- **Validation functions** (form validation, data validation)
- **Constants** (configuration values, enums)
- **Helper functions** (pure functions, calculations)
- **Supabase utilities** (database helpers, auth helpers)
