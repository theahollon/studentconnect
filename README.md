# StudentConnect

**StudentConnect** is a web-based platform developed as part of the course **TDT4140 – Programvareutvikling** at NTNU.

The goal of the project is to gather **student-relevant events and job advertisements** in one place, making it easier for students to discover opportunities and register for events.

The platform allows:
- **Users** to browse events and job advertisements
- **Users** to view detailed pages for each event and job posting
- **Users** to register for and unregister from events
- **Administrators** to create and manage events and job advertisements
- **Role-based access**, where selected users have administrator privileges

The project is developed using modern web technologies and follows **agile development principles**, with a focus on delivering a functional core system early and improving it iteratively.

This repository contains the source code for the application.
